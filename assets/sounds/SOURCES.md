# 효과음 출처와 이용 조건

게임에 넣는 소리 파일은 모두 여기에 한 줄씩 적는다. 조건을 확인하지 못한 소리는 넣지 않는다.
대표님이 직접 녹음한 소리는 출처에 "대표님 녹음"이라고 적는다.

- 파일 위치: `assets/sounds/s1-wNN/이름.mp3` (짧게, 한 파일 200KB 이하 권장)
- 형식: mp3 (휴대폰·PC 브라우저 모두 재생됨)
