# 회차 구성 양식 (채팅 ↔ 게임 개발 공통)

claude.ai 채팅에서 영상 대본을 쓸 때 이 양식을 함께 채우고, 완성본을 Claude Code 창에 그대로 붙여 넣습니다.
Claude Code는 이 양식을 기준으로 검증 → 스테이지 제작 → 체험 모드 테스트를 합니다.

---

## A. 게임 규칙 (기준서 11장, claude.ai 프로젝트 지식 파일로 올려 두기)

1. 한 회차 = 본 라운드 3개 + 선택형 숨은 주문 1개. 10분 안에 끝나는 분량(초3 기준).
2. 조작은 누르기만(끌어 놓기·자유 서술 없음). 예외: 영상 암호는 글자 입력, 숫자 답은 화면 숫자 버튼(0~9). 라운드 형태:
   - **칸 나누기**: 물건마다 칸(예: 고체/액체/기체) 고르기
   - **모두 고르기**: 조건에 맞는 것 전부 고르기
   - **3지선다**: 보기는 항상 3개 (그림 1장 곁들일 수 있음)
   - **숫자 맞추기**: 상자(100·10·1) 담기 또는 숫자 버튼
   - 새 형태가 필요하면 이유와 함께 적기
3. 오답 피드백은 방향만(많다/모자라다, 너무 크다/작다). 정답은 말하지 않음.
4. 힌트는 그 회차 진행 캐릭터가 말함. 2단계(① 개념 → ② 쪼개기). 2번 틀리면 힌트 권유(3지선다는 1번).
5. 진행 캐릭터는 2회마다 교대: 1~2회 규리사 → 3~4회 티포 → 5~6회 자판남 → 반복(영상 내레이터와 같음). 들어가기·힌트·결과 대사를 맡고, 나머지 둘은 라운드별 보조 진행. 말버릇·웃음:
   - **규리사**: "…인 거지." / "푸흡."
   - **티포**: 영어 한 단어 섞기 "음… not bad." / "쉬이익—"
   - **자판남**: "~입니다만." / "딸깍, 딸깍."
6. 암호는 영상에만 나오고, 게임 화면·해설·힌트·제목에 그 단어나 거의 같은 표현이 나오지 않음. 띄어쓰기는 무시.
7. 복습 문제(2주 후): 수학 회차는 숫자 답 3~4개, 과학 회차는 3지선다 3~4개.
8. 화면·대사에 실명·학교·연락처 없음. 아이들끼리 순위·대결·채팅 없음.
9. 용어는 "주차" 대신 "회차".
10. 과학·수학은 초3 교과서 기준으로 정확하게(예: 눈에 보이는 김은 기체가 아니라 작은 물방울). 사실에는 출처 1개 이상.
11. XP: 첫 클리어 100 / 힌트 없이 +50 / 숨은 주문 +30 / 영상 단서 20 / 복습 정답 40 / 공동 목표 10. 경험치는 첫 클리어 때만, 레벨 = 1 + XP÷200.

## C. 채워진 예시 (2회차 요약)

- 제목: 냉동고의 빈 병 / 교과: 과학 3-2 물질의 상태 / 개념 ID: `sci-state-01` / 진행: 규리사
- 핵심 개념: 공기(기체)도 공간을 채우고 무게가 있다
- 상식 포인트: 눈에 보이는 하얀 김은 기체가 아니라 작은 물방울
- 영상 암호: 영상에서 확인 / 질문: "영상에서 냉동고 문에 적힌 암호는?"
- 라운드 1 (규리사, 칸 나누기): 부엌 물건 9개 → 고체·액체·기체 (기체: 자전거 바퀴 속 공기, 풍선 속 공기, 빈 병 속 공기)
- 라운드 2 (티포, 모두 고르기): 다른 그릇에 옮겨도 모양이 그대로인 것
- 라운드 3 (자판남, 3지선다): 휴지 붙인 컵을 거꾸로 물에 넣으면? → 안 젖는다 + "컵 속에 공기가 먼저 들어 있어서 물이 못 들어왔어"
- 숨은 주문 (자판남, 3지선다): 풍선 막대 저울 → 바람 넣은 쪽 / 바람 뺀 쪽 / 그대로 수평
- 복습 (과학이라 3지선다): "자전거 바퀴 속 공기는 고체, 액체, 기체 중 무엇일까?" → 기체 등
