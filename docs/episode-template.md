# 회차 구성 양식 (채팅 ↔ 게임 개발 공통)

claude.ai 채팅에서 영상 대본을 쓸 때 이 양식을 함께 채우고, 완성본을 Claude Code 창에 그대로 붙여 넣습니다.
Claude Code는 이 양식을 기준으로 검증 → 스테이지 제작 → 체험 모드 테스트를 합니다.

---

## A. 채팅에 먼저 알려 줄 게임 규칙 (claude.ai 프로젝트 지식 파일로 올려 두기)

1. 한 회차 = 본 라운드 3개 + 선택형 숨은 주문 1개. 10분 안에 끝나는 분량 (초등 3학년 기준).
2. 조작은 **누르기만** (끌어 놓기·자유 서술 입력 없음). 쓸 수 있는 라운드 형태:
   - **칸 나누기**: 물건마다 칸(예: 고체/액체/기체) 고르기
   - **모두 고르기**: 조건에 맞는 것 전부 고르기
   - **3지선다**: 보기 3개 중 하나 (그림 1장 곁들일 수 있음)
   - **숫자 맞추기**: 상자(100·10·1)를 담아 수 만들기 (1회차 방식)
   - 새 형태가 필요하면 이유와 함께 적기
3. 오답 피드백은 **방향만** (많다/모자라다, 넘친다/모자란다). 정답은 말하지 않음.
4. 힌트는 **2단계**: ① 개념 → ② 구체적으로 쪼개기. 2번 틀리면 힌트를 권함 (3지선다는 1번 틀리면).
5. 진행 캐릭터와 말버릇 (오리지널, 바꾸지 않음):
   - **규리사**: "…인 거지." / 웃음 "푸흡." / 진행·힌트·과학·수학
   - **티포**: 영어 한 단어 섞기 "음… not bad." / "쉬이익—" / 영어·요리 과학
   - **자판남**: "~입니다만." / "딸깍, 딸깍." / 수학·경제
6. **암호**는 영상에만 나오고 게임 화면에는 나오지 않는 단어 (제목에 들어간 단어 X). 띄어쓰기는 무시됨.
7. **복습 문제**(2주 후 출제)는 **숫자로 답하는 문제** 3~4개.
8. 화면·대사에 실명·학교·연락처 넣지 않기. 아이들끼리 순위·대결 없음.
9. 용어는 "주차" 대신 "**회차**".
10. 과학·수학 내용은 초3 교과서 기준으로 정확하게 (예: 눈에 보이는 "김"은 기체가 아니라 작은 물방울).

## C. 채워진 예시 (2회차 요약)

- 제목: 냉동고의 빈 병 / 교과: 과학 3-2 물질의 상태 / 개념 ID: `sci-state-01`
- 핵심 개념: 공기(기체)도 자리를 차지하고 무게가 있다
- 영상 암호: `자리차지` / 질문: "영상에서 냉동고 문에 적힌 암호는?"
- 라운드 1 (규리사, 칸 나누기): 부엌 물건 9개 → 고체·액체·기체
- 라운드 2 (티포, 모두 고르기): 다른 그릇에 옮겨도 모양이 그대로인 것
- 라운드 3 (자판남, 3지선다): 휴지 붙인 컵을 거꾸로 물에 넣으면? → 안 젖는다 + "공기가 자리를 차지해서"
- 숨은 주문 (자판남, 3지선다): 풍선 막대 저울 → 바람 넣은 쪽이 내려간다
- 복습: "휴지 컵 4개 중 1개는 구멍… 젖지 않은 컵은 몇 개?" → 3개 등
